# COVID-19-Global-Data-Analysis-Trends-Mortality-and-Recovery-Insights-2020-2021-
End-to-end data analysis of COVID-19 global datasets (confirmed, deaths, recoveries) to uncover trends, mortality patterns, and recovery dynamics using Python (Pandas, Matplotlib).

🔹 Project Overview

This project performs a comprehensive analysis of COVID-19 data from January 2020 to May 2021, focusing on case progression, mortality rates, and recovery patterns across countries.
The goal is to transform raw cumulative datasets into meaningful insights using time-series analysis, aggregation techniques, and data cleaning strategies.
The analysis highlights how the pandemic evolved globally and how different countries responded in terms of healthcare outcomes.

🔹 Objectives

- Analyze trends in confirmed cases, deaths, and recoveries over time.
- Identify countries with highest mortality impact.
- Evaluate recovery efficiency using recovery-to-case ratios.
- Compare pandemic progression across regions.
- Detect anomalies and reporting inconsistencies in real-world data.

🔹 Dataset Description

  The project uses three time-series datasets:
- Confirmed Cases: cumulative daily infection counts.
- Deaths: cumulative fatalities.
- Recoveries: cumulative recovered cases.

Each dataset is structured in wide format (dates as columns) and transformed into long format for time-series analysis.
Key challenge: handling inconsistent date formats, missing values, and reporting anomalies.
